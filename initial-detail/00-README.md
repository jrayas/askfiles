# Askfiles: Obsidian Plugin Brief

This folder is a product brief for **Askfiles, an Obsidian plugin**. It describes what the plugin is, how it should feel, and what it should do. It deliberately contains no code and no implementation method. All technical decisions are left to the builder.

## One-line idea
A calm, question-by-question note creator for Obsidian where the **vault's folders act as the database**. Each answer narrows the next question, and the final step names the note.

## Plugin name
**Askfiles**: "ask, then file". The plugin asks simple questions and files the note in the right place. Use this name for the plugin display name, settings page heading, command labels and user-facing wording.

## Note on the ASCII references
The ASCII drawings are layout and behaviour references only. Symbols such as the padlock and gear stand in for proper line icons. The real plugin should follow the design principles, not copy the characters.
