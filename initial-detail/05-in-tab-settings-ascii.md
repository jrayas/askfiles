# In-Tab Settings (Gear Panel): ASCII Reference

**Icon legend:** `[unlocked]`, `[locked]` and `[gear]` are plain-text placeholders for a matching set of black line icons (open padlock, closed padlock, gear).

Opens from the gear icon in the main tab as a panel sliding in from the right, so the cards stay visible and every change previews live. Contains only quick options used in the moment. Heavier options live on the plugin settings page.

```
                                              Settings

                                              Folders
                                              Lock folder creation    ● On

                                              Layout
                                              View                    Grid
                                              Columns                 Auto
                                              Card size               Comfortable

                                              Titles
                                              Phrase mode             Random

                                              Apply to    This folder ▾

                                              More settings →
                                              Reset view
```

## "Apply to" confirmation
```
Apply to

  ● This folder only          (Knowledge)
  ○ Everywhere

  Everywhere will replace any folder-specific layouts.
                              [ Apply ]  [ Cancel ]
```

## Rules for this panel
- Few options only. The default look must be good without touching anything.
- Changes preview live behind the panel.
- "Apply to" chooses between this folder only and everywhere, which gives per-folder layout overrides without a separate screen.
- "More settings" opens the plugin settings page directly.
- "Reset view" restores layout defaults.
- The lock may appear both here and as the padlock in the top bar. The two must always agree, and toggling either updates the other immediately.
- Closing the panel: click the gear again, press Escape, or click outside it.

## Groups
1. Folders: the lock
2. Layout: view, columns, card size
3. Titles: phrase mode
