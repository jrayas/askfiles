# Open Questions

Decisions still to be made. The builder should propose sensible defaults and flag them.

1. Should "Type" (meeting, reference, idea, log and so on) be a folder level or a property chosen at the end? Current leaning: a property plus a template choice, to avoid repeating a "Meetings" folder everywhere.
2. Should card appearance (icon, colour, description) be stored inside each folder or in the plugin's central settings?
3. Should the gear open as a slide-in panel (preferred) or replace the page?
4. When someone stops early, does the final step still always ask for type and template? Current leaning: yes.
5. Where does the plugin live: a full tab, a sidebar panel, or a popup, or more than one?
6. Should the quick-jump search be on every page or only the first?
7. Which existing plugins overlap (for example QuickAdd, Templater, Modal Forms)? The gap this plugin fills is questions built dynamically from folder structure.
8. Plugin name is chosen: **Askfiles**. A spot check found no existing plugin with this name, but it is not a full verification. Re-check the community plugin list, GitHub and naming guidelines before submission. Avoid the word "Wizard", which is already used by another plugin.
